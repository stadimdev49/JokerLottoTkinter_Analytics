# 🎰 Advanced OPAP Lottery & Joker Analyzer

Προηγμένη εφαρμογή ανάλυσης και στατιστικής επεξεργασίας κληρώσεων για τα παιχνίδια **Τζόκερ** και **Λόττο** του ΟΠΑΠ, γραμμένη σε **Python** με χρήση της βιβλιοθήκης γραφικού περιβάλλοντος **Tkinter**. 

Το εργαλείο υποστηρίζει πλήρη αυτόματη λήψη δεδομένων από το API του ΟΠΑΠ, χειροκίνητη εισαγωγή κληρώσεων, πολυεπίπεδη ανάλυση ανά κατηγορία εμφανίσεων, ιστορική επαλήθευση με ίδιο πλήθος δεξαμενής, αλγόριθμο αυτόματης απόφασης, σύγκριση εύρους (5, 10, 15, 20 κληρώσεις) και άμεση εξαγωγή αναφορών σε **TXT** και **PDF**.

## ⚙️ Προϋποθέσεις (Prerequisites)

Για να τρέξετε την εφαρμογή στο σύστημά σας (δοκιμασμένο σε **Linux Ubuntu** καθώς και σε Windows/macOS), θα χρειαστείτε:

* **Python 3.8+**
* Βιβλιοθήκες Python:
  * `requests` (για την επικοινωνία με το API του ΟΠΑΠ)
  * `reportlab` (προαιρετικά, απαραίτητη μόνο για την εξαγωγή αρχείων PDF με ελληνικούς χαρακτήρες)

### Εγκατάσταση Απαιτούμενων Βιβλιοθηκών
Μπορείτε να εγκαταστήσετε τις απαραίτητες εξαρτήσεις εκτελώντας στο τερματικό σας:

```bash
pip install requests reportlab
